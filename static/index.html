容易踩的坑

授权码在哪里？和登录密码一样吗？

不一样，必须用授权码。QQ 邮箱：设置 → 账户 → 开启 SMTP → 生成授权码；163/126：设置 → POP3/SMTP/IMAP → 开启并设置授权码；Gmail：账号 → 安全性 → 应用专用密码；Outlook：账户 → 安全 → 应用密码。

「存草稿」和「直接发送」有什么区别？

存草稿只是写进你邮箱的草稿箱，不会发出，可以在网页邮箱里逐封检查后再点发送；直接发送会立刻投递，无法撤回。第一次建议先存草稿。

为什么发到一半停了？

常见三种：触发邮箱每日上限（QQ 个人约 50 封/天）、授权码失效、网络中断。失败的信不会记成「已投递」，修好后勾选「跳过已投递」重跑，只会补发失败的。

会被当成垃圾邮件吗？

短时间大量同文邮件容易触发。建议降到 10 封/分钟、主题带姓名和岗位、别用「群发」「通知」这类词、别一次发几百封。

没有 Excel，只有截图或 PDF 怎么办？

「收件人 → AI 输入」把文件拖进去就行：截图、PDF、Word、Excel、聊天记录都能读。一份材料里有多家公司会被拆成多条，没有邮箱的公司也会列出来标出来让你补。前提是先接上 AI（选一个提供商、粘一次 Key）。

AI 会看到我的简历吗？

只有你点「从简历自动填写」时，那份简历的文字才会发给你自己选的那家模型（DeepSeek / ChatGPT / Claude…）。不点就不上传，本程序自己的服务器也不保存任何内容。

表格里多加一列「岗位」能用在正文里吗？

能。除「公司名称 / 收件人邮箱 / 邮件主题」外的任何列都会变成变量，正文写 {岗位} 就替换成那一行的值。

我的授权码会被上传吗？

不会。它只写在你电脑的 ~/.resumemailer/config.json（权限 600），程序直接连你自己的邮箱服务器。
